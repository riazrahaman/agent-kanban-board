| `KANBAN_BACKUP_ENABLED` | server | Set truthy to enable periodic on-disk backups |
| `KANBAN_BACKUP_INTERVAL_MS` | server | Backup interval in milliseconds (default 600000) |
| `KANBAN_BACKUP_KEEP` | server | How many backup snapshots to retain (default 10) |
| `KANBAN_CLAIM_TTL_MS` | server | Lease TTL for a claimed task (default 600000) |

| `KANBAN_JOURNAL_COMPACT_BYTES` | server | Journal size that triggers compaction (default 1MB) |
