what broke, and what fixed it

The tunnel fix

The board on Railway needs the model running on this Mac. The old route — Tailscale's funnel — handed the connection to a DERP relay that reset every TLS handshake, so requests died in transit (ECONNRESET). The fix gives the model its own lane: the hostname ollama.riazrahaman.com is proxied at the Cloudflare edge, a cloudflared connector (kept alive by launchd) carries traffic home, and a token-guarded gateway on :11435 proxies straight into Ollama on :11434.

What actually changed

  1. DNS — ollama.riazrahaman.com became the one proxied (orange-cloud) record; the rest stay grey-clouded (DNS only).
  2. Connector — cloudflared runs as a launchd agent with RunAtLoad + KeepAlive: the tunnel is up at boot and restarts if it dies.
  3. Path — Cloudflare edge → gateway on :11435 that demands a token (401 without one) → Ollama on :11434. No mesh relay in between.
  4. Retired — the Tailscale funnel route, whose DERP relay kept resetting the handshake.
