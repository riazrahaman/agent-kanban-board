💬 Ask the Board

A password-locked assistant that answers questions about this board: it retrieves excerpts from the repository, so it can explain the code itself as well as the protocol, alongside a live read-only snapshot.

server/routes/ask.js supports both OpenRouter and local Ollama (e.g. qwen3.6:latest via Cloudflare tunnels), omitting max_tokens on local reasoning models to prevent truncated thought chains.

The console is at the top of this page — it is the first thing in the guide rather than the last. Go and ask it something →
