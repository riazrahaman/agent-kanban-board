Running it on your own machine

Install

git clone …/agent-kanban-board
cd agent-kanban-board
npm --prefix server install
npm --prefix client install
npm run build

Run

export KANBAN_AUTH_TOKEN="demo-secret"
npm start

API and the built UI on one port: localhost:4000

There is no root npm install

Server and client each carry their own manifest. Installing at the root gets you nothing.

Never launch through an npm wrapper

A wrapper intercepts SIGTERM, so every clean shutdown is reported as a crash. Use npm start at the root, or node directly.

Check it is really up

curl -s localhost:4000/api/health
