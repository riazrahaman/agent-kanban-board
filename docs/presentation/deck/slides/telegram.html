Get told when a card comes back

Two variables. Both required — alerts stay off until both are set.

export KANBAN_TELEGRAM_BOT_TOKEN="… from @BotFather"
export KANBAN_TELEGRAM_CHAT_ID="-1001234567890"

A group id is negative. No dependency is added — the server calls the Bot API over HTTPS directly.

Make one fire on stage

Claim a card with lease_ms: 60000, then say nothing. A minute later the reaper takes it back — live, in front of them.

It cannot flood you

Sends are serialized with a minimum gap, so a sweep that reclaims twenty cards does not trip Telegram’s rate limit.

It cannot break the board

A failed delivery never affects the reclaim itself. The card returns to READY either way.
