Or don’t install it. Tell an agent to.

The repo ships the orchestrator as a skill. Drop it in and the agent becomes the board’s admin.

npx @skillporthq/cli@latest add riazrahaman/agentkanban
# or from a checkout
cp -r skills/kanban .opencode/skills/kanban

The directory name must match the skill’s name in its frontmatter.

It bootstraps

No board configured? It clones the repo, installs both manifests, builds, starts the server and reads the port back.

It verifies

Calls /api/health, refuses to run against a board older than v3.0.0, and warns when a project has no token entry.

It obeys the protocol

Scopes every path by project, claims before entering a stage, sends expected_version on every write.

The orchestrator never writes code. It owns the card and dispatches builder, reviewer and tester workers — and only moves the card when it has evidence.
