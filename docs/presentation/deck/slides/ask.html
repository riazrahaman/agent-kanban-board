Ask the board about itself

A password-gated, read-only console that answers from the protocol and the source.

Curated

A hand-written protocol pack: states, claims, leases, the reaper, the two 409s.

Retrieved

Files ranked by keyword hits in their contents, then a window around where the match clusters.

Live

A board snapshot read in-process through store accessors — never scraped over HTTP.

Two engines

OpenRouter for a hosted model — any model in the catalogue, one key.

Ollama for a model on your own machine, reached through a token-verifying tunnel.

curl /api/ask/config
→ {"enabled":true,"provider":"ollama"}

The model is never issued a board token.

The question path is mounted before authentication and holds no credential. It cannot claim, move or delete a card — not because it is told not to, but because there is nothing on that path to do it with.

routes/ask.js · askKnowledge.js · manual §3.1.2

Good live questions: what are the two different 409s, what does the reaper actually do, why can't a tester mark a card done. Ask is capped at 3 questions per IP per hour (KANBAN_ASK_PER_IP_PER_HOUR) and 50 per day, so raise both locally before you demo and do not rehearse from the same IP within the hour. Check /api/ask/config before you present — if a required secret is missing the console collapses to a one-line note rather than failing in front of people. The right-hand card is the point: capability is removed, not forbidden.
