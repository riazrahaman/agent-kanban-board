Run these against the local board with the browser visible so each call lands on screen. Every call bumps the version, so take each expected_version from the previous response. The 403 only lands from READY_TO_SHIP: the server checks the edge before the role, so a tester closing an IN_PROGRESS card returns 409 Invalid state transition instead. If you are short on time, seed the card beforehand and run only the three failures.
